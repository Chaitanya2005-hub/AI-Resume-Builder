# AI Resume Architect

A powerful, AI-driven resume builder that creates professional, ATS-optimized resumes in minutes.

## Features

- **Magic Mode**: Paste unstructured text or an old resume and let AI architect it.
- **Manual Mode**: Fill in details step-by-step for complete control.
- **AI Optimization**: Uses Gemini 1.5 Flash to rewrite bullet points with strong action verbs.
- **PDF Export**: Generate high-quality, professional PDFs instantly.
- **Responsive Design**: Works perfectly on mobile and desktop.
- **Theme Support**: Includes both Light and Dark modes.

## How to Publish to Your GitHub

Since this app is built in a cloud environment, you need to manually push the code to your repository:

1. **Initialize Local Git Repository**:
   ```bash
   git init
   ```

2. **Add Your Remote**:
   ```bash
   git remote add origin https://github.com/Chaitanya2005-hub/AI-Resume-Builder
   ```

3. **Stage and Commit**:
   ```bash
   git add .
   git commit -m "Initialize AI Resume Architect with Magic Mode and PDF Export"
   ```

4. **Push to GitHub**:
   ```bash
   git branch -M main
   git push -u origin main
   ```

## Tech Stack

- **Framework**: Next.js 15
- **UI**: React, Tailwind CSS, ShadCN UI
- **AI**: Genkit, Gemini 1.5 Flash
- **PDF Generation**: html2canvas, jsPDF
